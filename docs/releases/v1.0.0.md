The first release of Seed Placement Randomizer, for Windows and macOS.

## What it does

- Places 1–10 seeds at random in a 90 mm dish, at least 15–20 mm apart and 10 mm from the rim
- Puts each dish in a random empty slot on a 10-slot rack, numbered from the top left
- Gives every dish a layout code. Enter a code to place that exact dish again
- Shows each dish's seeds with coordinates in millimetres
- Lets you label dishes on tape, such as "Control A"
- Exports a run as a CSV of seed positions, a picture of the rack, and printable 1:1 templates to
  set each dish on
- Saves the run as you go and restores it the next time you open the app
- Offers five bench colours and five seed drawings

## Download

**Windows:** download `SeedPlacementRandomizer-1.0.0-win-x64.exe` and run it. No installation or
.NET is needed. Windows may warn that the app is from an unknown publisher, because it isn't
code-signed. Choose **More info**, then **Run anyway**.

**macOS:** download the zip for your Mac (`osx-arm64` for Apple silicon, `osx-x64` for Intel),
unzip it and move the app to Applications. The first time, right-click the app and choose **Open**,
because it isn't notarized by Apple.

## Printing templates

Print the templates at actual size (100%). Each page has a line that should measure 50 mm; if it
doesn't, the printer scaled the page.
