Seed Placement Randomizer now has a Linux build, alongside Windows and macOS. Nothing else changes
from 1.1.0.

## Download

**Windows:** download `SeedPlacementRandomizer-1.1.1-win-x64.exe` and run it. No installation or
.NET is needed. Windows may warn that the app is from an unknown publisher, because it isn't
code-signed. Choose **More info**, then **Run anyway**.

**macOS:** download the zip for your Mac (`osx-arm64` for Apple silicon, `osx-x64` for Intel),
unzip it and move the app to Applications. The first time, right-click the app and choose **Open**,
because it isn't notarized by Apple.

**Linux:** download `SeedPlacementRandomizer-1.1.1-linux-x64.tar.gz`, then extract and run it:

```sh
tar -xzf SeedPlacementRandomizer-1.1.1-linux-x64.tar.gz
./SeedPlacementRandomizer
```

It is self-contained and needs no .NET install.
