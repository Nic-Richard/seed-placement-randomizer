Seed Placement Randomizer now runs on Android phones, and a run can move between the computer and
the phone.

## What's new

- **An Android app** with everything the desktop app does: placing dishes, the rack, the inspector,
  labels, layout codes and exports. On a phone the bench and rack sit above the controls, and
  **Place a dish** stays at the top of them.
- **Save** writes the whole rack to a `.seedrun` file, and **Open** loads one, on every
  platform. Copy the file over a USB cable to take a run from the computer to the bench and back.
- On a computer, drag a `.seedrun` file onto the window to open it. Opening a run asks first when
  the rack already has dishes.
- **Share** on the phone sends the file to email, a chat app or cloud storage.
- **Export** on the phone saves the seed positions, rack picture and templates to
  `Downloads/Seed Placement/`, ready to copy to a computer.
- The rack controls now sit under **Rack**, and Export, Open and Save under a new **Run** section.

Runs saved by earlier versions open normally.

## Download

**Android 10 or later:** download `SeedPlacementRandomizer-1.2.0-android.apk` on the phone and open it.
Android asks once to allow installs from the app you opened it with. Later versions install over
this one and keep the saved run.

**Windows:** download `SeedPlacementRandomizer-1.2.0-win-x64.exe` and run it. No installation or
.NET is needed. Windows may warn that the app is from an unknown publisher, because it isn't
code-signed. Choose **More info**, then **Run anyway**.

**macOS:** download the zip for your Mac (`osx-arm64` for Apple silicon, `osx-x64` for Intel),
unzip it and move the app to Applications. The first time, right-click the app and choose **Open**,
because it isn't notarized by Apple.

**Linux:** download `SeedPlacementRandomizer-1.2.0-linux-x64.tar.gz`, then extract and run it:

```sh
tar -xzf SeedPlacementRandomizer-1.2.0-linux-x64.tar.gz
./SeedPlacementRandomizer
```

It is self-contained and needs no .NET install.
